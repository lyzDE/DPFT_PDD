# DPFT_PDD
# Dual-Stream Progressive Fusion Transformer for Phone-Related Pedestrian Distraction Detection

This repository contains the official implementation of **DPFT** for phone-related pedestrian distraction detection.

DPFT is a dual-stream progressive fusion Transformer framework that jointly leverages **RGB images** and **pose keypoints** to capture complementary appearance and human posture information for robust pedestrian distraction detection.
